# Security policy

## Report a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub's private
vulnerability reporting feature for this repository. If that feature is not
available, contact the repository owner privately.

Include the affected version, reproduction steps, impact, and a proposed fix if
you have one. Do not include private keys or personal data.

## Deployment scope

Peer definitions and generated files are public. Repository access controls who
can change them. Protect the deployment branch with required reviews, require
MFA for writers, and restrict workflow changes. Never commit a private key.
